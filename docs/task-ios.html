Chia task theo sprint – ChiNhanh iOS

Lập ngày 20/10/2026 · Căn cứ: kế hoạch iOS (duyệt ngày 20/10/2026), đặc tả iOS

Hiện mới chia sprint iL: 12 task, 22 giờ. iL bắt đầu ngay sau khi Android xong S0 (tuần 3–4 theo lịch chung). Các sprint iS0 đến iS8 sẽ được chia trước khi bắt đầu iS0, tương ứng 107 task Android, cộng thêm các task riêng của iOS.

1. Về sprint iL

  • Mục đích: học đủ nền Swift, Xcode và SwiftUI trước khi viết code sản phẩm. Chưa có FR nào.
  • Code để ở đâu: thư mục luyen-tap/ trong repo iOS. Thư mục này không phải code sản phẩm, nhưng vẫn commit để làm được trên nhiều máy, và để agent rà tiến độ theo git như bình thường.
  • Hai dự án luyện tập:
    • luyen-tap/SwiftCoBan: Swift package, chỉ có logic và test. Chạy bằng swift test hoặc trong Xcode.
    • luyen-tap/SachDoc: app SwiftUI quản lý danh sách sách đang đọc. Chủ đề này cố ý khác app chi tiêu, để ví dụ không biến thành lời giải cho task sản phẩm.
  • Quy tắc mentor vẫn giữ nguyên: bạn tự viết toàn bộ code. Agent soạn lý thuyết vào docs/hoc/ (repo tài liệu), hướng dẫn từng bước và rà soát.
  • Cổng 0 (task iL-12): mentor hỏi để kiểm tra 5 khái niệm: value type và reference type, optional, ARC, actor isolation, identity trong SwiftUI.

2. Quy ước

  • Mã task: iL-<số thứ tự> cho sprint làm quen, iS<sprint>-<số thứ tự> cho các sprint sản phẩm, ví dụ iS2-05. Thứ tự trong bảng chính là thứ tự nên làm.
  • Git: nhánh task/iL-03-swift-co-ban; commit đang làm dở [iL-03][wip] ...; commit đóng task [iL-03] .... Mã task có tiền tố i nên không trùng với commit [S0-03] của repo Android. Mỗi lần commit có hai bước: commit trong docs/ trước (tiến độ, hoc/), rồi commit ở repo iOS kèm con trỏ submodule, cùng mã task (mục 13.4 của luật).
  • Kích thước: mỗi task tối đa 3,5 giờ, tức khoảng 1–2 buổi làm.
  • Phụ thuộc: chỉ ghi những task phải xong trước. Các task thuộc sprint trước được coi là đã xong.
  • Xong khi: đạt nội dung ở cột "Chi tiết và tiêu chí xong". Từ iS0 trở đi áp dụng thêm định nghĩa Hoàn thành chung của kế hoạch iOS. Riêng iL không áp dụng phần String Catalog, snapshot test và CI, vì đây là code luyện tập.
